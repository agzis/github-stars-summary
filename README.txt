GitHub Stars Summary
====================

项目地址：
https://github.com/agzis/github-stars-summary

项目简介
--------

本仓库整理 GitHub 账号 agzis 收藏的高 Star 开源项目，并按照项目的主要用途进行单一归类。

当前报告基于 2026-11-05 的快照：171 个公开收藏项目中，共收录 142 个 Star 数不少于 10,000 的项目。

主要文件
--------

github-stars-10k-classified.md
    完整分类报告，包含分类概览、项目 Star 快照、一句话介绍和适用人群。

AGENTS.md
    面向维护者和编码 Agent 的编辑、分类与一致性检查规则。

分类原则
--------

- 每个项目只按主要用途归入一个分类。
- Agent 本体、多 Agent 编排框架和 Agent 工作台分别归类。
- 终端与会话环境、本地效率工具和第三方服务 CLI 分别归类。
- 学习资料、研究评测、数据资源和 Notebook 环境分别归类。
- 安全工具与部署、运维、网络工具分别归类。
- Star 数会随时间变化，报告中的数值仅代表统计时点的快照。

维护说明
--------

调整项目归属时，需要同步更新分类概览、章节编号和项目数，并检查：

- 各分类项目数与表格行数一致；
- 分类数之和与总项目数一致；
- 项目没有遗漏或重复；
- 分类内项目按记录的 Star 数降序排列。

安全说明
--------

安全、OSINT、网络代理和媒体下载类工具应仅在法律、服务条款及明确授权允许的范围内使用。
